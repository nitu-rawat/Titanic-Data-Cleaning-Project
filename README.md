# Titanic Data Cleaning Project

## Overview
This project is part of Week 1 of the Machine Learning & AI Course.

## Objective
To perform data preprocessing and cleaning on the Titanic dataset.

## Tasks Performed
- Loaded Titanic dataset using Pandas
- Explored dataset using .info() and .describe()
- Handled missing values using median and mode imputation
- Encoded categorical features (Sex, Embarked)
- Visualized Age Distribution using Matplotlib
- Exported cleaned dataset to CSV

## Tools & Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn
- Google Colab

## Output
- Cleaned Titanic Dataset (cleaned_titanic.csv)
- Data Visualization Graph
- Preprocessed Dataset Ready for Machine Learning
